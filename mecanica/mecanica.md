# Mecánica
### Chasis:
El chasis constituye la esructura fundamental de nuestro robot. Dicha estructura nos permite soportar todos los componentes del robot dándonos la capacidad de transportarlos. Además el diseño del chasis proporciona un mayor equilibrio mientras nuestro vehículo se desplaza por el circuito. Además, también se buscó un material relativamente ligero para mejorar la velocidad de nuestro robot.

### Motor trasero unidireccional:
Este mecanismo nos ayuda a poder controlar el robot de manera más rápida y sencilla haciendo posible el desplazamiento del mismo. Este motor nos otorga la fuerza necesaria para desplazar el robot de forma estable y continua a lo largo del circuito .

### Servomotor:
El servomotor proporciona la fuerza junto a un eje de direcciones que nos permite controlar la orientación del robot de manera curvilínea y unidireccional. Junto al mecanismo anterior podemos controlar el mismo.
